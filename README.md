# Система управления образовательными учреждениями

Веб-приложение для управления образовательными учреждениями с поддержкой курсов, записей студентов и обратной связи.

## Возможности

- ✅ **5+ страниц**: Главная, Курсы, Вход/Регистрация, Личный кабинет, Обратная связь, Админ-панель
- ✅ **База данных**: JSON файлы для хранения данных (пользователи, курсы, записи, обратная связь, расписание, учебные процессы)
- ✅ **Три роли пользователей**: Администратор, Преподаватель, Студент
- ✅ **История для авторизованных**: История записей на курсы и просмотров
- ✅ **Формы**: Регистрация, вход, запись на курс, обратная связь
- ✅ **Обработка HTTP ошибок**: Страницы ошибок 400, 401, 403, 404
- ✅ **Сервер на чистом Node.js**: Без использования фреймворков
- ✅ **Клиентская часть**: HTML, CSS и JavaScript
- ✅ **Панель администратора**: Управление пользователями, расписанием, учебными процессами и курсами

## Установка и запуск

### Требования

- Node.js версии 12.0.0 или выше

### Шаги установки

1. Клонируйте репозиторий или скачайте проект
2. Откройте терминал в корневой директории проекта
3. Установите зависимости (если требуется):
   ```bash
   npm install
   ```
4. Запустите сервер:
   ```bash
   npm start
   ```
   или
   ```bash
   node server.js
   ```

5. Откройте браузер и перейдите по адресу:
   ```
   http://localhost:3000
   ```

## Использование

### Тестовые учетные записи

В системе уже созданы тестовые пользователи:

**Администратор:**
- Имя пользователя: `admin`
- Пароль: `admin123`
- Доступ: Полный доступ к системе, включая админ-панель

**Студент:**
- Имя пользователя: `student1`
- Пароль: `student123`

**Преподаватель:**
- Имя пользователя: `teacher1`
- Пароль: `teacher123`

### Основные функции

1. **Главная страница** (`/`)
   - Обзор системы
   - Просмотр популярных курсов
   - Навигация по сайту

2. **Курсы** (`/courses.html`)
   - Просмотр всех доступных курсов
   - Для авторизованных пользователей: запись на курс
   - Для неавторизованных: предложение войти в систему

3. **Вход/Регистрация** (`/login.html`)
   - Регистрация нового пользователя
   - Вход в систему
   - Сохранение сессии через cookies

4. **Личный кабинет** (`/dashboard.html`)
   - Просмотр профиля пользователя
   - Список записей на курсы
   - История обучения
   - Прогресс по курсам

5. **Обратная связь** (`/feedback.html`)
   - Форма для отправки сообщений
   - Автозаполнение для авторизованных пользователей
   - Доступна для всех пользователей

6. **Панель администратора** (`/admin.html`)
   - Управление пользователями (создание, редактирование, удаление)
   - Управление расписанием занятий
   - Управление учебными процессами и модулями
   - Управление курсами
   - Фильтрация пользователей по ролям
   - Доступна только для администраторов

### API Endpoints

Сервер предоставляет следующие API endpoints:

- `POST /api/register` - Регистрация нового пользователя
- `POST /api/login` - Вход в систему
- `POST /api/logout` - Выход из системы
- `GET /api/me` - Получение информации о текущем пользователе
- `GET /api/courses` - Получение списка всех курсов
- `GET /api/courses/:id` - Получение информации о курсе
- `POST /api/enroll` - Запись на курс (требуется авторизация)
- `GET /api/my-enrollments` - Получение записей текущего пользователя
- `POST /api/feedback` - Отправка обратной связи

### Административные API (требуется роль admin)

**Управление пользователями:**
- `GET /api/admin/users` - Получение списка пользователей (опционально: `?role=student|teacher|admin`)
- `GET /api/admin/users/:id` - Получение пользователя по ID
- `POST /api/admin/users` - Создание нового пользователя
- `PUT /api/admin/users/:id` - Обновление пользователя
- `DELETE /api/admin/users/:id` - Удаление пользователя

**Управление расписанием:**
- `GET /api/admin/schedule` - Получение списка занятий
- `GET /api/admin/schedule/:id` - Получение занятия по ID
- `POST /api/admin/schedule` - Создание нового занятия
- `PUT /api/admin/schedule/:id` - Обновление занятия
- `DELETE /api/admin/schedule/:id` - Удаление занятия

**Управление учебными процессами:**
- `GET /api/admin/processes` - Получение списка модулей
- `GET /api/admin/processes/:id` - Получение модуля по ID
- `POST /api/admin/processes` - Создание нового модуля
- `PUT /api/admin/processes/:id` - Обновление модуля
- `DELETE /api/admin/processes/:id` - Удаление модуля

**Управление курсами:**
- `DELETE /api/admin/courses/:id` - Удаление курса

## Обработка ошибок

Сервер обрабатывает следующие HTTP ошибки:

- **400** - Неверный запрос (Bad Request)
- **401** - Не авторизован (Unauthorized)
- **403** - Доступ запрещен (Forbidden)
- **404** - Страница не найдена (Not Found)

Для каждой ошибки отображается соответствующая страница с описанием проблемы.

## Технические детали

### Хранение данных

Все данные хранятся в JSON файлах в директории `data/`:
- `users.json` - пользователи системы
- `courses.json` - каталог образовательных курсов
- `enrollments.json` - записи студентов на курсы
- `feedback.json` - сообщения обратной связи
- `sessions.json` - активные пользовательские сессии

### Авторизация

Система использует сессии на основе токенов, хранящихся в cookies. При входе создается уникальный токен сессии, который используется для идентификации пользователя.

### Безопасность

⚠️ **Важно**: Это учебный проект. В продакшн-версии необходимо:
- Хешировать пароли (использовать bcrypt)
- Использовать HTTPS
- Валидировать и санитизировать все входные данные
- Использовать реальную базу данных вместо JSON файлов
- Реализовать CSRF защиту

## Разработка

Проект использует:
- **Сервер**: Node.js с модулями `http`, `fs`, `path`, `url`, `querystring`
- **Клиент**: Vanilla JavaScript (без фреймворков)
- **Стили**: CSS3 с использованием Flexbox и Grid
- **Хранение данных**: JSON файлы
