# Система управления образовательными учреждениями (PERN Stack)

Веб-приложение для управления образовательными учреждениями с поддержкой курсов, записей студентов и обратной связи.

## Технологический стек

- **Backend**: Node.js + Express + PostgreSQL
- **Frontend**: React + TypeScript + Vite
- **База данных**: PostgreSQL

## Возможности

- ✅ **5+ страниц**: Главная, Курсы, Вход/Регистрация, Личный кабинет, Обратная связь, Админ-панель
- ✅ **База данных**: PostgreSQL для хранения всех данных
- ✅ **Три роли пользователей**: Администратор, Преподаватель, Студент
- ✅ **Система прогресса**: Студенты могут отправлять ответы на уроки, преподаватели проверяют и обновляют прогресс
- ✅ **Расписание занятий**: Преподаватели создают уроки с текстом, ссылками и изображениями
- ✅ **Формы**: Регистрация, вход, запись на курс, обратная связь
- ✅ **Панель администратора**: Управление пользователями, расписанием, учебными процессами и курсами

## Установка и запуск

### Требования

- Node.js версии 16.0.0 или выше
- PostgreSQL 12 или выше
- npm или yarn

### Шаги установки

1. **Клонируйте репозиторий или скачайте проект**

2. **Установите зависимости:**
   ```bash
   npm run install:all
   ```
   Или отдельно:
   ```bash
   npm install
   cd frontend && npm install
   ```

3. **Настройте базу данных PostgreSQL:**
   - Создайте базу данных:
     ```sql
     CREATE DATABASE educational_system;
     ```
   - Выполните схему:
     ```bash
     psql -U postgres -d educational_system -f db/schema.sql
     ```

4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта:
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=educational_system
   DB_USER=postgres
   DB_PASSWORD=your_password
   PORT=3000
   ```

5. **Соберите фронтенд:**
   ```bash
   npm run build:frontend
   ```
   Или:
   ```bash
   cd frontend && npm run build
   ```

6. **Запустите сервер:**
   ```bash
   npm start
   ```

7. **Откройте браузер и перейдите по адресу:**
   ```
   http://localhost:3000
   ```

### Режим разработки

Для разработки с hot-reload:

**Терминал 1 (Backend):**
```bash
npm run dev
```

**Терминал 2 (Frontend):**
```bash
npm run dev:frontend
```

Frontend будет доступен на `http://localhost:5173` с автоматическим проксированием API-запросов на `http://localhost:3000`.

## Использование

### Тестовые учетные записи

После выполнения `schema.sql` в системе будут созданы тестовые пользователи:

**Администратор:**
- Имя пользователя: `admin`
- Пароль: `admin123`
- Доступ: Полный доступ к системе, включая админ-панель

**Студент:**
- Имя пользователя: `student1`
- Пароль: `student123`

**Преподаватель:**
- Имя пользователя: `teacher1`
- Пароль: `teacher123`

### Основные функции

1. **Главная страница** (`/`)
   - Обзор системы
   - Просмотр популярных курсов
   - Навигация по сайту

2. **Курсы** (`/courses`)
   - Просмотр всех доступных курсов
   - Для авторизованных пользователей: запись на курс
   - Для неавторизованных: предложение войти в систему

3. **Вход/Регистрация** (`/login`)
   - Регистрация нового пользователя
   - Вход в систему
   - Сохранение сессии через cookies

4. **Личный кабинет** (`/dashboard`)
   - Просмотр профиля пользователя
   - Список записей на курсы с прогресс-барами
   - Расписание занятий для записанных курсов
   - Отправка ответов на уроки

5. **Обратная связь** (`/feedback`)
   - Форма для отправки сообщений
   - Автозаполнение для авторизованных пользователей
   - Доступна для всех пользователей

6. **Панель администратора** (`/admin`)
   - Управление пользователями (создание, редактирование, удаление)
   - Управление расписанием занятий
   - Управление учебными процессами и модулями
   - Управление курсами
   - Фильтрация пользователей по ролям
   - Доступна только для администраторов

### API Endpoints

**Аутентификация:**
- `POST /api/register` - Регистрация нового пользователя
- `POST /api/login` - Вход в систему
- `POST /api/logout` - Выход из системы
- `GET /api/me` - Получение информации о текущем пользователе

**Курсы:**
- `GET /api/courses` - Получение списка всех курсов
- `GET /api/courses/:id` - Получение информации о курсе
- `POST /api/enroll` - Запись на курс (требуется авторизация)
- `GET /api/my-enrollments` - Получение записей текущего пользователя

**Расписание и уроки:**
- `GET /api/my-schedule` - Получение расписания для студента (только записанные курсы)
- `POST /api/lessons/:id/answer` - Отправка/обновление ответа на урок (студент)

**Преподаватель:**
- `GET /api/teacher/schedule` - Получение занятий преподавателя
- `POST /api/teacher/schedule` - Создание нового урока
- `GET /api/teacher/lessons/:id/submissions` - Получение ответов студентов на урок
- `POST /api/teacher/lessons/:lessonId/submissions/:submissionId/review` - Проверка ответа (зачесть/не зачесть)

**Обратная связь:**
- `POST /api/feedback` - Отправка обратной связи

### Административные API (требуется роль admin)

**Управление пользователями:**
- `GET /api/admin/users` - Получение списка пользователей (опционально: `?role=student|teacher|admin`)
- `GET /api/admin/users/:id` - Получение пользователя по ID
- `POST /api/admin/users` - Создание нового пользователя
- `PUT /api/admin/users/:id` - Обновление пользователя
- `DELETE /api/admin/users/:id` - Удаление пользователя

**Управление расписанием:**
- `GET /api/admin/schedule` - Получение списка занятий
- `GET /api/admin/schedule/:id` - Получение занятия по ID
- `POST /api/admin/schedule` - Создание нового занятия
- `PUT /api/admin/schedule/:id` - Обновление занятия
- `DELETE /api/admin/schedule/:id` - Удаление занятия

**Управление учебными процессами:**
- `GET /api/admin/processes` - Получение списка модулей
- `GET /api/admin/processes/:id` - Получение модуля по ID
- `POST /api/admin/processes` - Создание нового модуля
- `PUT /api/admin/processes/:id` - Обновление модуля
- `DELETE /api/admin/processes/:id` - Удаление модуля

**Управление курсами:**
- `DELETE /api/admin/courses/:id` - Удаление курса

## Технические детали

### Хранение данных

Все данные хранятся в PostgreSQL:
- `users` - пользователи системы
- `courses` - каталог образовательных курсов
- `enrollments` - записи студентов на курсы с прогрессом
- `schedule` - расписание занятий с контентом (текст, ссылки, изображения)
- `lesson_submissions` - ответы студентов на уроки
- `feedback` - сообщения обратной связи
- `sessions` - активные пользовательские сессии
- `educational_processes` - учебные процессы и модули

### Авторизация

Система использует сессии на основе токенов, хранящихся в cookies. При входе создается уникальный токен сессии, который используется для идентификации пользователя.

### Безопасность

⚠️ **Важно**: Это учебный проект. В продакшн-версии необходимо:
- Хешировать пароли (использовать bcrypt)
- Использовать HTTPS
- Валидировать и санитизировать все входные данные
- Реализовать CSRF защиту
- Использовать переменные окружения для секретов
